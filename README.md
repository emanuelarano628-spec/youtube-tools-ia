# 📈 YouTube Trends Finder

Encuentra qué está en tendencia en YouTube AHORA MISMO
para crear contenido que aproveche el momento.

**Creado por IA Práctica**
📺 [youtube.com/@IAPractica](https://youtube.com/@IAPractica)

---

## ¿Qué hace?

- 🔥 Videos trending en YouTube por país y categoría
- 📊 Score de tendencia basado en vistas, likes y velocidad de crecimiento
- 💡 Ideas concretas de contenido basadas en las tendencias del momento
- 📋 Exporta resultados a CSV con links directos a cada video

---

## Instalación

```bash
pip install google-api-python-client pandas tabulate
```

## Configuración

1. Obtén tu API Key gratis en console.cloud.google.com
2. Habilita **YouTube Data API v3**
3. Abre el archivo y reemplaza:

```python
API_KEY = "tu_api_key_aqui"
```

## Uso

```bash
python youtube_trends_finder.py
```

El script te guía paso a paso con un menú interactivo.
